## 二、Finding 列表

### F-01（p2）水平方向形态完全未声明

- **位置锚点**：D-r1、D-r9、C-04、C-09；§2 非目标。
- **被违反的依据**：Task 1 第 2 条（滚动全程流畅、成本解耦，未排除水平维）；
  设计文档规范「每条原子、单一陈述、可验证」——水平维无任何可验证陈述。
- **证据**：E-01 只实测了垂直 wheel 平移（probe-drive.mjs 的 `wheel(0,240)` 仅动
  `zoomLayer.y`）；D-r9 只决策了垂直滚动条（全高来自 `orderAtom.length × rowH`）；
  C-04 槽位 bounds `width:表宽` 但「表宽」与视口宽（C-21 测量环境 1440px）的关系
  无任何条款；列数 ≥8（C-01）且列宽可拖拽调大（C-15），列总宽超过视口宽的路径
  真实存在；wheel 横向 / shift+wheel 行为未求证、水平滚动条有无未决策、D-r10 的
  列反解依赖的水平偏移口径未声明。
- **建议修正**：新增条款或修订 C-04/C-09 声明水平形态（「列总宽适配视口、无水平
  滚动」或「水平滚动模型 + 水平滚动条 + wheel 横向行为」），并给出对应决策记录
  与否选项。
- **修复验证标准**：文档中存在可验证的水平形态条款；D-r9 或新决策记录含水平滚动
  结论；C-09 验收口径明确是否覆盖水平滚动。

### F-02（p2）sticky 表头机制缺失，且 W-02 声明无条款锚定

- **位置锚点**：进度账本 W-02（「DOM 滚动条、sticky 表头」）；§3 决策记录
  （无表头条目）；§4（无表头条款）；§6 追溯矩阵（W-02 仅映射 C-05、C-09，
  二者均无表头内容）。
- **被违反的依据**：设计文档规范「工作项……细节通过规范性条款 ID 引用」与
  追溯矩阵的覆盖要求；Task 1 第 6 条（列拖动以表头为交互载体）。
- **证据**：E-03 实测单 `Leafer` 场景下 `zoomLayer === leafer`
  （probe-structure.mjs），`zoomLayer.move()` 平移的是整个 leafer——同层渲染的
  表头会随内容一起滚走；sticky 需要机制（反平移绑定 / 独立层 / 第二个 Leafer），
  文档没有任何条款或决策记录定义该机制；表头同时是列拖动（C-15）与列宽拖拽的
  交互载体，其实现形态影响 D-r6 幽灵节点所在层与事件坐标口径。
- **建议修正**：新增表头形态条款（sticky 机制、所在层、与列拖动/列宽拖拽的关系）
  及对应决策记录；W-02 声明改引该条款。
- **修复验证标准**：存在表头条款且 W-02 在追溯矩阵中映射到它；条款含可验证判据
  （如「滚动任意距离后表头纵向位置不变」）并能挂接 D-03 冒烟断言。

### F-03（p2）编辑写回后的在屏刷新路径未声明，与 C-02 存在张力

### F-04（p2）底衬高亮的失效通道未声明，按原文实施高亮会 stale

- **位置锚点**：C-06（「底衬失效」）；§5「斑马底衬」（选中/查找高亮叠加在
  斑马底衬上）；W-04。
- **被违反的依据**：代码事实（见证据）；Task 1 第 4 条（命中行定位呈现）与
  D-r10（单击选行）的正确性依赖。
- **证据**：DotLayer 的内建失效只订阅空间索引变更（`src/dotLayer.ts:126-138`），
  而槽位索引在排序 / 选中变化 / 查找命中变化时不产生任何索引变更（这正是
  D-r2/C-06 的设计目标）；`DotLayer.invalidate()` 在无累积脏区时直接返回
  （`src/dotLayer.ts:199-200`），应用层没有公共 API 触发整层或视口重绘。
  既有配方是显式接线：`autorun(() => { selected(); leafer.forceRender() })`
  （`playground/stress.tsx:433-438`，注释自承「纯数据变更不产生 leafer 脏区 →
  手动整层失效」）。设计文档只说 C-06 允许「底衬失效」，未声明任何接线机制；
  按原文实施（只创建 DotLayer）排序后选中/命中高亮停留在旧槽位。
- **建议修正**：在 C-06 或新条款中声明失效接线（订阅 orderAtom / 选中集 / 命中集
  变化 → 对视口区域 `forceRender`，参照 stress.tsx 配方），并在 D-03 冒烟中增加
  「排序后选中高亮出现在新槽位」的断言。
- **修复验证标准**：条款含具体接线机制与触发源枚举；冒烟存在高亮跟随断言。
